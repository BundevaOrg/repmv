# repmv

Лендинг-визитка репетитора по математике Маргариты Владимировны — https://repmv.ru

Статический сайт без сборки: `index.html`, `styles.css`, `script.js`, `privacy.html`, `favicon.svg`.

## Перед публикацией

- `script.js` → `CONFIG`: ник в Telegram, телефон и `endpoint` для приёма заявок (POST JSON: Formspree, Getform, свой воркер с Telegram-ботом). Пока `endpoint` пуст, заявка копируется в буфер, и посетителю предлагается отправить её в Telegram.
- Заглушки фото (`.ph`) в `index.html`: портрет в hero, фото в «Обо мне», скриншоты отзывов. Помечены комментариями `ЗАГЛУШКА`.
- Реквизиты в подвале и данные оператора в `privacy.html` (помечены `TODO`).
- `og:image` 1200×630 для превью в мессенджерах.
